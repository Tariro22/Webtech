## Accessibility Issue and Fix

### Issue
The profile image did not initially have alternative text, which could make it difficult for users who use screen readers to understand the image.

### Fix
I added an `alt` attribute to the image to provide a meaningful description of the picture.

Example:

```html
<img src="..." alt="Tariro's profile picture">
